DNAT

Kernel destination-NAT (iptables): traffic to a public port on this host is rewritten to an internal host:port. Faster than userspace forwarding and supports UDP. Leave SNAT on for internal/VPN targets (rewrites the return path so replies come back); turn it off to preserve the client's real source IP when the target already routes replies through this host. Changes apply immediately.
