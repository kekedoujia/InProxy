HTTP service

Each domain reverse-proxies path prefixes to internal HTTP backends. inproxy terminates TLS with an automatic Let's Encrypt cert (DNS must point here), routes by (domain, longest path prefix), and can strip the prefix. A path that matches no route falls back to a Domains whole-site rule for that host. Changes apply immediately.
